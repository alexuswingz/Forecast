DEPLOYMENT INSTRUCTIONS
=======================

1. CREATE ZIP FILE
------------------
zip -r forecast-lambda.zip lambda_function.py


2. UPLOAD TO AWS LAMBDA
-----------------------
- Go to AWS Lambda Console
- Create new function or select existing
- Upload forecast-lambda.zip
- Set Runtime: Python 3.9


3. ADD PSYCOPG2 LAYER
---------------------
- In Lambda function configuration
- Add Layer -> Custom layers
- Select your existing psycopg2 layer


4. SET ENVIRONMENT VARIABLES
-----------------------------
Configuration -> Environment variables -> Edit

Add these variables:
- DB_HOST: forecast.cf6s2y8ae04j.ap-southeast-2.rds.amazonaws.com
- DB_PORT: 5432
- DB_NAME: kpi_metrics
- DB_USER: postgres
- DB_PASSWORD: [your password]

IMPORTANT - Lambda Configuration:
- Memory: 512 MB (minimum)
- Timeout: 60 seconds (CRITICAL for /metrics and /planning endpoints)
- Concurrent executions: 10

CRITICAL - Database Indexes (REQUIRED):
Run ADD_INDEXES.sql on your RDS database to add performance indexes.
Without these indexes, queries will timeout!

Connect to RDS:
psql -h forecast.cf6s2y8ae04j.ap-southeast-2.rds.amazonaws.com -U postgres -d kpi_metrics

Then run:
\i ADD_INDEXES.sql


5. CONFIGURE API GATEWAY
-------------------------
Create REST API with these routes:

GET  /products           -> Lambda: forecast-lambda
GET  /planning           -> Lambda: forecast-lambda
GET  /product/{asin}     -> Lambda: forecast-lambda
GET  /forecast/{asin}    -> Lambda: forecast-lambda
GET  /chart/{asin}       -> Lambda: forecast-lambda
GET  /sales-chart/{asin} -> Lambda: forecast-lambda
GET  /ads-chart/{asin}   -> Lambda: forecast-lambda
GET  /metrics/{asin}     -> Lambda: forecast-lambda

Enable CORS on all routes.
